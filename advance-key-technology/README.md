# Advance Key Technology Website

Responsive static website recreated from the supplied Exocoetus reference screenshots, with branding/content changed to **Advance Key Technology**.

## Files
- `index.html` - complete responsive website
- `style.css` - desktop/tablet/mobile styling
- `script.js` - mobile menu, dropdown and contact-form demo

## Run
Open `index.html` directly in a browser.

## Replace before publishing
Update the phone number, email, address, logo and any company-specific text in `index.html`.

The current contact form is a front-end demo. Connect it to your .NET/API/email service before production.
